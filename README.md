# Roszada

A daily logic puzzle. Take apart what is already on the table to make room for
what is in your hand.

Prototype: one HTML file. No dependencies, no server, no data collection,
no login.

**Design, rules, boards and prototype: Paweł Wronowski.**

Demo version prepared for the "Nowa gra w aplikacji Wyborczej" competition
(Wyborcza sp. z o.o., September 2026).

The mechanic descends from the classic rummy family, which is in the public
domain. The name, artwork, board set, generator and code are original and
remain the property of the author.
